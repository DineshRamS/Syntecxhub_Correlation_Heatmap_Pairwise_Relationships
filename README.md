# Syntecxhub Correlation Heatmap & Pairwise Relationships

## Project Overview

This project is part of the Syntecxhub Data Science Internship Week 2 tasks.

The project analyzes relationships among numeric features in IPL delivery data using Pearson correlation and pairwise visualization techniques.

## Analysis Performed

- Selected relevant numeric features from the IPL deliveries dataset
- Computed Pearson correlation coefficients
- Created an annotated correlation heatmap
- Masked the upper triangle of the correlation matrix
- Created a pairwise relationship plot
- Identified the strongest positive and negative relationships

## Key Findings

- Batsman runs and total runs: 0.98
- Wide runs and extra runs: 0.72
- Legbye runs and extra runs: 0.55
- Batsman runs and extra runs: -0.11
